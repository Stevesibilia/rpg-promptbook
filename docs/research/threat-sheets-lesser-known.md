# Threat sheets in four lesser-known games

Tags: [SRC] = read in a source this session; [MEM] = from my own knowledge, not verified; [SECOND] = second-hand (review or fan guide).

## 1. Vileborn

**Identity.** Vileborn, "a nobledark TTRPG", by Claudio Pustorino; publisher Horrible Guild (Italy); Kickstarter 2024, core book 250+ pp, English edition (Italian origin) [SRC]. Free Quickstart with the adventure "Lex Umbræ" [SRC]. Source: https://horribleguild.com/us/wp-content/uploads/2024/07/VILEBORN_Quickstart_EN.pdf (I read the printer-friendly copy at https://horribleguild.com/eu/wp-content/uploads/2025/01/VILEBORN_Quickstart-Printer-Friendly_EN.pdf).

**Threat sheet = "Challenge" page** (quickstart pp. 54-57, 72-73) [SRC]. A challenge is anything needing more than one success; a "reviled" (monster) is a challenge with a Darkness die section. Fields in order:

1. Type line: "CHALLENGE / <KIND>" (e.g. CLAWSHROWDER, FALLEN): free text.
2. Name: free text.
3. Quote: free text, one line.
4. Six approach difficulties, arranged around the portrait: Force, Subterfuge, Precision, Reason, Influence, Willpower. Each a number (4 easy, 5 normal, 6 difficult, 7 very difficult). Printed per approach, so one threat can be hard by Force and easy by Reason.
5. Resistances: list of 0-3 named tags (each +1 difficulty when met). Weaknesses: list of 0-3 named tags (each -1 difficulty when exploited). Drawn as small labelled slots beside the portrait.
6. HITS: box track, N boxes (N not visible in the text extraction; per challenge, likely 4-8; unknown). Boxes = successes needed to finish it.
7. Description paragraph: free text.
8. CHALLENGE EVENTS: free text keyed to a hit count ("On the 3rd hit, X transforms; Force/Precision become 7; roll the darkness die from now on").
9. UNIQUE RULES: free text (e.g. "cannot be killed").
10. COMPLICATIONS: list of 5 lines, each "narration; mark <condition>" (wound, fear, exhaustion, shame, anger, insecurity).
11. DARKNESS DIE (reviled only): "Roll d12 for each test... If you roll N+" then a table of threshold -> effect (e.g. 7+, 8+, 11+ with a test and a condition). The core book adds per-profile "behavior, actions, narrative suggestions" [SRC, product blurb].

**Example (made up).**

```
CHALLENGE / FALLEN — Hollow Bailiff — "Your debt is mine."
Force 6  Subterfuge 5  Precision 6  Reason 4  Influence 5  Willpower 7
Resistance: Cold iron-clad | Weakness: Holy oil, Guilt
HITS: [ ][ ][ ][ ][ ][ ]
Events: 3rd hit -> becomes incorporeal; only Willpower works.
Unique: leaves if the debt is paid.
Complications: chains lash you; mark a wound / ...; mark fear
Darkness die d12: 6+ whispering, Willpower 5 or fear; 9+ everyone wounds
```

**What the GM tracks.** Hits ticked (N boxes), complications collected (the guide counts them, "from the third complication..." is a trigger), whether darkness die is active, and each PC's conditions/wounds (PC side). Printed sheet: six difficulty numbers, resistance/weakness slots, one box row, event text, complication list, a threshold table.

**Derived values.** None computed by rule from another field. Adjustments at play time: weakness -1, resistance +1 on the stated difficulty (may leave the 4-7 range). Darkness thresholds are authored per reviled; for improvised ones the guide gives 9+/6+/3+ for weak/normal/strong darkness [SRC].

**Other sheet kinds.** PC sheet (approaches d6/d8/d10, training, conditions boxes, wounds, background, dark heritage with boxes and gifts that mark per use) [SRC]; pregens in the quickstart [SRC]; scenes/events in adventures; the core book has factions/places (not seen).

**Confidence: high** for challenge anatomy (read directly). Unknown: hit box counts, the full Reviled bestiary profile (the core book may add fields), no vehicles or factions seen.

## 2. Historia (D&D 5e)

**Identity.** Historia, "Dark Fantasy Renaissance Setting for 5e", by Mana Project Studio (Italy, same publisher as Not the End); Kickstarter, a Corebook (MPS10003?) and an Adventures book (MPS10005) exist; Italian edition "Historia - Manuale Base" sold at uplay.it [SRC listing]. Setting Vesteria, anthropomorphic animal folk (Familiae), lower magic, factions, careers with ranks and prestige, "Ventures", optional Battle Royal rules for armies [SRC: https://geeknative.com/68375/historia-could-this-work-dark-renaissance-fantasy-dd-and-anthros and Kickstarter page https://www.kicktraq.com/projects/manaprojectstudio/historia-dark-fantasy-renaissance-setting-for-5e/]. Caveat: I matched the name to this product; the user did not confirm the publisher.

**Threat stat block.** I found no source showing the Historia stat block. It is a 5e supplement, so the expected structure is the standard 5e block [MEM, not verified against Historia]:
name; size, type, alignment (free text); Armor Class (number + note); Hit Points (number + dice expression, derived: Nd(size) + CON mod x N); Speed (list); six ability scores with modifiers (derived: floor((score-10)/2)); saving throws, skills, damage vulnerabilities/resistances/immunities, condition immunities, senses, languages (lists); Challenge (number + XP; proficiency bonus derived from CR); traits (name + text list); Actions, Bonus actions, Reactions, Legendary actions (named entries with attack bonus, reach, damage dice).
No evidence of Historia-specific fields. Possible differences (unverified): animal Familiae as NPC species, faction ranks and Prestige for NPCs.

**GM tracks.** HP (a number, or a box row for printed sheets), legendary action uses, recharge flags, spell slots; faction standing if factions are tracked.

**Derived values.** Ability modifier from score, proficiency bonus from CR, HP from dice, attack bonus = mod + proficiency, save DC = 8 + prof + mod (all [MEM], plain 5e).

**Other sheet kinds.** PC (5e sheet + career rank/Prestige, Familia) [SRC summary]; factions (new faction rules) [SRC summary]; Ventures (not understood); armies for Battle Royal.

**Confidence: low** for Historia-specific stat blocks (none found); high for generic 5e structure. To resolve: read the Historia Adventures book preview on DriveThruRPG.

## 3. Not the End (Mana Project Studio / Fumble GDR, HexSys)

**Identity.** Not the End, by Mana Project Studio with the Italian podcast Fumble GDR; HexSys, diceless token-bag system; Italian original, English Corebook (about 236-240 pp), Modiphius/Mana Project; Italian RPG of the Year 2020, 2024 ENnies winner [SRC retail pages]. Source: https://www.drivethrurpg.com/product/369261/Not-The-End--Corebook ; rules summary https://indiegamereadingclub.com/indie-game-reading-club/minimum-viable-game-not-the-end-and-others . I could not open the Corebook (Scribd copy blocked, not read).

**Threat structure.** From the rules summary, there is no antagonist stat block; the opposition is the fiction plus two numbers set on the spot [SRC, secondhand; MEM that the book offers example "Dangers" but this is unverified]:

- Difficulty: number (count of GM stones/negative tokens placed in the bag).
- Danger: number (how many GM stones the player must draw to be taken out of the scene).
- Optional: complications the GM may introduce when handed negative tokens (free text).
- Hero-side modifiers affecting the bag: Misfortunes (negative traits add GM stones), Scars (add one GM stone), a "risky" action (the GM keeps the stones).

**Example (made up, in this shape).**

```
Obstacle: Rain-slick roof chase
Difficulty: 4   Danger: 2
Complications on offer: lose the satchel; the guard sees your face
```

**GM tracks.** The bag contents per test (positive tokens from traits, GM stones from difficulty, misfortunes, scars), tokens spent, which hero traits are used, scars. A printed sheet should offer: Difficulty number, Danger number, free-text complications list, and optionally a token-count row. No health track for enemies.

**Derived values.** Difficulty becomes a token count; Hero traits (up to the used number) become the player's tokens; Misfortune adds to GM stones. All applied at test time, not stored.

**Other sheet kinds.** Hero sheet: hexagon "hive" of keywords/traits, misfortunes, scars, Evolve rules; Settings are built by the group ("Create Settings"); Stories modules (retail listing "Not the End - Stories").

**Confidence: low-medium.** Unknown: whether the Corebook gives named Dangers/antagonist templates, "confusion" and "adrenaline" are not part of anything I found (they are Outgunned/other-game terms; probably not in NTE).

## 4. Outgunned (Two Little Mice)

**Identity.** Outgunned, cinematic action RPG, Two Little Mice (Italy, Free League distribution), English core rulebook 2023; d6 pools, matching dice; Outgunned Adventure and Outgunned Superheroes variants. GM role is the "Director". Source: https://en.wikipedia.org/wiki/Outgunned and the Alchemy summary https://help.alchemyrpg.com/en/articles/10167249-outgunned .

**Threat structure.** Three enemy classes: Goons, Bad Guys, Bosses [SRC]. Fields (partially confirmed, field order [MEM]/[SECOND]):

1. Name, class: free text.
2. Grit: box track, N boxes (goons shared across the group; each success scores 1 Grit damage) [SRC]. Bosses and some Bad Guys have Hot Boxes on the track giving them Adrenaline for special actions [SECOND, sources disagree about whether Bad Guys have them].
3. Defense: success-difficulty tier (Basic / Critical / Extreme / Impossible); players attack against it [SRC].
4. Attack: a count and tier, e.g. "ATK 2 Critical"; heroes' reaction rolls must meet it or lose Grit; extra successes can protect an ally [SRC].
5. Feats / special actions: short text lines (Bad Guys, Bosses; card decks exist) [SECOND].
6. Group flag: a goon "enemy" can be a mob; many enemies hit everyone at once [SECOND].
   Enemies have no Death Roulette; at 0 Grit they are knocked out [SRC].

**Example (made up).**

```
GOONS — Warehouse thugs
Grit: [ ]x6   Defense: Basic   Attack: 1 Basic
Feat: Swarm (hits everyone in reach)
BOSS — Don Varga
Grit: [ ]x10 with last box Hot   Defense: Critical   Attack: 2 Critical
Feat: Human shield; special action costing 1 Adrenaline
```

(Numbers invented.)

**GM tracks.** Grit boxes ticked per enemy or mob, Adrenaline spent by bosses on Hot Boxes, who has acted this round. Printed sheet: box row, defense tier, attack tier and number, feat lines.

**Derived values.** Hero Grit is 12 boxes [SRC]. Enemy Grit is a fixed number per entry; I found no formula (a forum note mentions a thug listed with 6 vs 9 Grit between combat example and Bestiary [SECOND]). Damage: Attack count per failed reaction = Grit lost [SECOND]. Death Roulette and Hot Box only for heroes except boss Hot Boxes.

**Other sheet kinds.** Hero sheet: Role, Trope, Feats, Attributes with Skills (d6 pools), 12 Grit boxes, Adrenaline, Death Roulette, Gear; Vehicles (with chases, Handling etc.) [MEM]; Bestiary/Directors resources, cards of enemies.

**Confidence: medium** on structure (goon/bad guy/boss, Grit, Defense, Attack tiers, Hot Boxes), low on exact field order and counts. Unknown: how many Grit boxes each tier typically has, exact format of Bosses' special actions.

## Not the End: confirmed by the owner (2026-11-06, from the corebook chapter «Narrare le storie», paraphrased)

A challenge ("sfida") can be a person, a place or an object. Same sheet for all three:

1. Short description (prose).
2. Tests ("Difficoltà e pericolo delle prove"): a list of rows. Each row = an action (text), a difficulty and optionally a danger.
   - Difficulty: a word plus a number of black tokens: facilissimo/molto facile 1, facile 2, medio 3, difficile 4, difficilissimo 5, quasi impossibile 6, or impossibile (no number).
   - Danger: a word plus "leave the scene when drawing N black": estremamente 1, molto 2, abbastanza 3, poco 4, or per niente (none). Optional per row.
   - The first row is usually the general one ("facing it"), later rows are specific actions.
3. Possible misfortunes ("Possibili sventure"): list of short tags.
4. Possible complications ("Possibili complicazioni"): list of sentences.
5. Background ("Approfondimenti"): prose.
6. Advanced challenge only: one or two special rules (prose), how tokens are spent or drawn differently.

Nothing is tracked on the sheet: no boxes, no clocks. Design needs: a repeating row with typed cells (text + scale value + optional scale value), scales mapping a word to a number, and the same sheet type for persons, places and objects.

Owner answers: Historia = plain 5e stat blocks. Grit (Outgunned) and Vileborn hit-box counts unknown to the owner. Well-known systems played by the book.
