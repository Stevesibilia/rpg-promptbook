Mockup notes · #59
Screen
  • Generate through (1): each account picks Atelier or OpenRouter in Settings → Image generation. Both can be set up; only the chosen one is used. A choice is off until its credentials are in.
  • Atelier: the address is the server's (set by whoever runs Promptbook), so you only paste a write API token made in Atelier → Settings → API tokens. Stored encrypted, like the OpenRouter key. Saving checks it and shows the token's name, when it expires and the month against Atelier's cap (1).
  • A server with no Atelier address (1c) shows Atelier as unavailable; OpenRouter works as today.
  • Generate (2) says which one it goes through, with a link to change it. Same two models and shapes; prices are that provider's estimates (Atelier averages its last real costs, so GPT shows about $0.08 today).
  • Through Atelier, the images also land in an Atelier collection named after the project, made on the first Generate. The viewer (4) links each image to Atelier.
  • Errors come back in Atelier's words on the prompt, such as the monthly cap (6). Nothing is charged for a failed image.
  • Spending in Settings and «Generated here» count both providers; images made before stay as they are.
  • Unchanged and not shown: Midjourney prompts, NPC and handout cards, desktop offline. See image-generation.html.
